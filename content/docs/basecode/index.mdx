Basecode is a coding agent by Cencori that runs on your own machine. You point it at a project folder, describe what you want, and it reads the code, edits files, runs commands and tests, and reports what it actually observed.

It is a desktop application rather than a hosted one because the work is local: your repository, your toolchain, your test suite, your dev server. Only the model requests leave your machine, and they go through your Cencori project.

## What you need

- **macOS.** Basecode Desktop ships as a `.dmg` for Apple Silicon and Intel.
- **A Cencori account.** Basecode signs in with the same account you use for the dashboard.
- **A project with model access.** Basecode calls models through your Cencori project, so the project needs to be able to reach at least one model. See [Models in Basecode](/docs/basecode/models).

## Sign in

Basecode uses your browser for sign-in rather than asking for an API key.

1. Open Basecode and choose **Continue with Cencori**.
2. Your browser opens `cencori.com/basecode/sign-in`. Sign in if you are not already.
3. Approve the request. The browser hands the session back to the app through the `basecode://` link.

The exchange uses PKCE, so no long-lived secret is copied between the browser and the app. Signing out of Basecode ends that device's session and leaves your browser session alone.

Each installation registers as a device on your account, so you can see and revoke individual machines from the dashboard.

## Open a workspace

A workspace is a folder on your machine. Basecode can only read and edit files inside the workspace you open, and every task is scoped to it.

Open a folder, type what you want, and send it. Basecode plans, reads the files it needs, and starts working. You will see the commands it runs and the files it touches as it goes.

## Review before you keep anything

Basecode captures the previous contents of every file it edits before the edit lands, so a change is never one-way.

- **Change review** shows a diff of everything the current task touched.
- **Undo** restores the files a task changed, using the contents captured at the time of the edit.

Because Basecode captures those contents at the file-editing boundary, the agent is instructed to make workspace file changes through its editing tool rather than through shell redirection — that is what keeps the restore point complete.
