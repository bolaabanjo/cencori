The chat endpoint provides conversational AI capabilities with support for streaming, tool calling, and multiple providers.

## Basic Request

```typescript
const response = await cencori.ai.chat({
  model: 'gpt-4o',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ]
});

console.log(response.content);
```

## Request Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `model` | string | Yes | Model identifier |
| `messages` | array | Yes | Conversation messages |
| `temperature` | number | No | Randomness (0-2) |
| `maxTokens` | number | No | Maximum output tokens |
| `stream` | boolean | No | Enable streaming |
| `tools` | array | No | Available functions |

## Response

```typescript
{
  id: 'chatcmpl-...',
  content: 'Hello! How can I help you today?',
  model: 'gpt-4o',
  finishReason: 'stop',
  usage: {
    promptTokens: 15,
    completionTokens: 10,
    totalTokens: 25
  },
  toolCalls: null
}
```

## Streaming

```typescript
const stream = cencori.ai.chatStream({
  model: 'claude-sonnet-4.5',
  messages: [{ role: 'user', content: 'Tell me a story' }]
});

for await (const chunk of stream) {
  process.stdout.write(chunk.delta);
}
```

## Vision Auto-Routing

When a chat request contains image content, Cencori transparently routes it through the Vision analyzer — no code changes on your side. If the model you picked isn't vision-capable, Cencori upgrades it to the vision-capable equivalent in the same family:

- `gpt-3.5-turbo` → `gpt-4o-mini`
- `claude-3-5-haiku-latest` → `claude-3-5-sonnet-latest`
- `claude-3-haiku-20240307` → `claude-3-5-haiku-latest`
- `gemini-2.0-flash` → `gemini-2.5-flash`

Vision-capable models pass through unchanged.

```typescript
// You pick claude-3-5-haiku — no vision support natively.
// Cencori sees the image, routes through Vision on claude-3-5-sonnet-latest.
const response = await cencori.ai.chat({
  model: 'claude-3-5-haiku-latest',
  messages: [{
    role: 'user',
    content: [
      { type: 'text', text: 'What is in this image?' },
      { type: 'image_url', image_url: { url: 'https://example.com/photo.jpg' } }
    ]
  }]
});
```

The response is a normal `chat.completion` — same shape as any other chat call, so nothing on your side has to change.

### How you know an upgrade happened

Two response headers are set when Cencori swaps the model:

- `X-Model-Upgraded: true`
- `X-Model-Original: <the model you requested>`

`response.model` reflects the model that actually ran. Cost is calculated from the model that actually ran, not the one you originally asked for.

### Supported content shapes

Cencori detects images in any of these formats:

- OpenAI-style: `{ type: 'image_url', image_url: { url: '...' } }`
- Anthropic-style: `{ type: 'image', source: { type: 'base64', media_type: '...', data: '...' } }` or `{ source: { type: 'url', url: '...' } }`
- Responses API-style: `{ type: 'input_image', image: '...' }`

If multiple images are in a single request, the last one is used. For multi-image analysis, call `/api/ai/vision` directly.

## HTTP API

```bash
curl -X POST https://cencori.com/api/ai/chat \
  -H "CENCORI_API_KEY: csk_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```
