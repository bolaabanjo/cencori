Vision is live on Cencori.

Analyze, describe, OCR, and classify images across GPT-4o, Claude, and Gemini through one endpoint. Ships with a drop-in React uploader and works with any model — even the ones that don't natively support vision.

One API. Any model.

Send an image through the regular chat endpoint with any model — Cencori auto-routes it through Vision and upgrades to a vision-capable equivalent when needed. No more "which model supports vision?" checklist.

// You picked claude-3-5-haiku. No vision support natively.
// Cencori sees the image, upgrades to claude-3-5-sonnet, routes through Vision.
const response = await cencori.ai.chat({
  model: 'claude-3-5-haiku-latest',
  messages: [{
    role: 'user',
    content: [
      { type: 'text', text: 'What is in this image?' },
      { type: 'image_url', image_url: { url: 'https://...' } }
    ]
  }]
});

Four endpoints, one shape

  • POST /api/ai/vision — general analysis with your own prompt
  • /vision/describe — rich description
  • /vision/ocr — extract text (temp=0)
  • /vision/classify — structured JSON tags/categories

The UI is in the SDK too

Every AI platform ships an API. Cencori ships you the UI:

import { VisionUploader } from 'cencori/react';

<VisionUploader
  endpoint="/api/vision/describe"
  task="describe"
  onResult={(r) => console.log(r)}
/>

Drag-drop, client-side format validation, auto-compression for oversize JPEG/PNG/WEBP, and clean error banners. Drop it into your app and skip building the upload UX yourself.

Five SDKs, one shape

Vision is available today in TypeScript, Python, Go, PHP, and Rust — same four methods, same response shape, same error codes. Each ships with a runnable examples/vision.* file.
